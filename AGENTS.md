# Agent Instructions for microsandbox-tui

A Rust TUI application for managing MicroSandboxes, built with [ratatui](https://ratatui.rs/).
All sandbox communication goes through the official [`microsandbox`](https://crates.io/crates/microsandbox) Rust SDK
([source](https://github.com/superradcompany/microsandbox), [docs](https://docs.microsandbox.dev/sdk/rust/sandbox)).

## MicroSandbox SDK

SDK documentation: <https://docs.microsandbox.dev/sdk/rust/sandbox>
Runnable examples: <https://github.com/superradcompany/microsandbox/tree/main/examples/rust>

For all Rust-specific coding conventions read `.agents/instructions/rust.instructions.md`
